# 📉 ML STUDY PREDICTOR - WINDOWS SETUP

This is a Classical Machine Learning app using Scikit-Learn.
It predicts study workload based on statistical data.

### REQUIREMENTS
1. Install Python 3.11 or 3.12.
2. IMPORTANT: Check "Add Python to PATH" during installation.

### HOW TO RUN
1. Double-click "run_windows.bat".
2. Wait for it to install 'scikit-learn' and 'gradio'.
3. The App will open in your browser.

### FEATURES
1. Predict Tab: Enter your stats to get a schedule.
2. Teach Tab: Enter new data (e.g. "Robotics") to retrain the brain instantly.
